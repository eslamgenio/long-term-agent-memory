# Hermes User Profile

## Stable preferences and context
- The user wants Hermes to use an Obsidian vault on disk as external persistent memory.
- This vault is intended to improve long-term knowledge retention beyond the active context window.
- The user prefers a hybrid vault-management model: Hermes may autonomously manage routine notes, links, indexes, and session/reference/procedure updates, but should ask before major restructures, bulk renames/deletions, or schema changes.

## Notes
- Store durable preferences and stable conventions here when they matter across sessions.
- Avoid storing secrets or ephemeral task state.
